# Alcance del sistema

El sistema permitirá administrar las distintas actividades de una veterinaria que también cuenta con una tienda de productos para mascotas.

* **Gestión de clientes:** Permitirá registrar y actualizar los datos de los clientes, tanto de los dueños de las mascotas como de las personas que compren productos en la tienda.

* **Gestión de mascotas:** Permitirá registrar los datos de cada mascota, como su nombre, especie, raza, edad, peso y fecha de nacimiento, entre otros.

* **Gestión de veterinarios y especialidades:** Permitirá registrar los datos de los veterinarios y las especialidades de cada uno.

* **Gestión de consultas y tratamientos:** Se registrarán las consultas, operaciones, tratamientos y vacunaciones realizadas a las mascotas, junto con los medicamentos indicados. Esta información permitirá consultar el historial médico de cada mascota.

* **Gestión de productos y stock:** Permitirá registrar los productos disponibles para la venta y para el uso veterinario, controlando las cantidades existentes y sus precios. Las existencias se actualizarán según las compras, ventas y utilización de los productos.

* **Gestión de compras y proveedores:** Permitirá registrar los proveedores y los productos que suministran, incluyendo las cantidades y los precios de compra.

* **Gestión de ventas:** Se registrarán las ventas realizadas, incluyendo los productos vendidos, las cantidades y los precios unitarios. Esto permitirá consultar el detalle de cada venta y generar un comprobante con los importes correspondientes.

* **Gestión de métodos de pago:** Se registrará el método de pago utilizado en cada venta, ya sea efectivo, tarjeta de crédito, tarjeta de débito o transferencia.

* **Consultas e informes:** El sistema permitirá consultar información sobre las ventas, los productos vendidos, el stock disponible, los tratamientos realizados y otros datos registrados en la base de datos.
